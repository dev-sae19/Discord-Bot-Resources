## 🧐 What Even Is This File?

This is the **contribution guide** — a set of simple rules so that everyone who adds something to the list does it the same clean way. GitHub shows this file automatically when someone opens a Pull Request (a request to add their changes to your repo).

---

## ✅ What You Can Add

- A library, framework, or wrapper for building Discord bots
- A hosting platform, database, or infrastructure tool
- A useful API or integration for bot features
- A learning resource (video, guide, course, docs)
- A community or Discord server for bot developers
- A tool that makes bot development easier or faster

---

## ❌ What NOT to Add

- ❌ Resources that are **abandoned / not maintained** (no commits in 2+ years)
- ❌ **Duplicate** entries already in the list
- ❌ **Affiliate or referral links** — plain URLs only
- ❌ Resources **unrelated** to Discord bot development
- ❌ Your own project unless it's genuinely useful to others
- ❌ Paid resources without a meaningful free tier (unless truly exceptional)

---

## 📋 How to Add a Resource (Step by Step)

### If you know Git:

1. **Fork** this repo (click the `Fork` button in the top-right)
2. **Clone** your fork to your computer
3. **Edit** `README.md` and add your resource in the right section
4. **Commit** with a clear message like: `➕ Add Wavelink to Python music libraries`
5. **Push** and open a **Pull Request** back to this repo
6. Wait for review — usually fast!

### If you don't know Git:

1. Open an **[Issue](../../issues/new)** in this repo
2. Use the title: `[ADD] Resource Name — Section Name`
3. Include the name, URL, description, and cost (Free / Paid / Freemium / OSS)
4. The maintainer will add it for you ✅

## 📐 Formatting Rules

Please follow this exact format when adding a new entry to the table:

```markdown
| [Resource Name](https://link.com) | Short description of what it does and why it's useful. | ![Badge](url) |
```

### Badge options — copy the right one:

```markdown
<!-- Free (100% free, no limits) -->
![Free](https://img.shields.io/badge/FREE-57F287?style=flat-square)

<!-- Open Source -->
![OSS](https://img.shields.io/badge/OSS-5865F2?style=flat-square)

<!-- Freemium (has a free tier but also paid plans) -->
![Freemium](https://img.shields.io/badge/FREEMIUM-FEE75C?style=flat-square&labelColor=333)

<!-- Paid (no meaningful free option) -->
![Paid](https://img.shields.io/badge/PAID-ED4245?style=flat-square)
```

## 🗂️ Section Rules

| Rule | Detail |
|------|--------|
| **Alphabetical order** | Keep all entries A→Z within their section |
| **Right section** | Add to the most relevant category |
| **New section** | Open an Issue first to discuss before creating a new section |
| **⭐ marker** | Only the maintainer adds the ⭐ to highlight top picks |
